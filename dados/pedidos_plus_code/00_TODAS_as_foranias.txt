Preciso localizar no Google Maps estas 211 igrejas e capelas católicas da Arquidiocese de Florianópolis (SC), organizadas por forania e paróquia.

Para CADA linha com código, procure a igreja no Google Maps (nome + localidade + município) e me devolva UMA linha neste formato exato:
CÓDIGO | Plus Code completo do Google Maps (ex.: 5GQ4+XW Palhoça) | endereço que aparece no Google Maps

Regras:
- Mantenha o CÓDIGO de cada linha (ex.: PAL07).
- O Plus Code fica na ficha do lugar no Google Maps (o código com "+", ao lado do ícone de localização).
- Se não encontrar a igreja no Google Maps, escreva: CÓDIGO | NÃO ENCONTRADA
- Não invente nem use o endereço de outra igreja ou da matriz. Prefiro "NÃO ENCONTRADA" a um palpite.
- Responda só com a lista, uma linha por igreja, na mesma ordem.
- Se a resposta ficar longa demais, pare no fim de uma forania e eu peço para continuar a partir do próximo código.
